Why synthetic is the right choice here

The subject of this project is drift detection. To claim a detector works you must know what it was supposed to detect. With a public lending dataset you can compute a PSI, but you cannot say whether a quiet month means the population was stable or the detector was insensitive, because nobody knows the true schedule. Here the schedule is written down below, which is why the drift page can end with a table that scores each detector against the drift it was meant to catch, including the months it was late by. The trade-off is real and is stated plainly on the model card: the model is being tested on a world simple enough to write down.

Age, income, debt ratio and credit history are drawn from a correlated Gaussian copula (Cholesky factor of a fixed 4x4 correlation matrix), so they are not independent. true_pd is stored for inspection only and is never a model feature.

The default model

logit P(default) = b0 + intercept_shift(month) + {{ truth.coefficients.z_age }} * (age - 40)/12 + {{ truth.coefficients.z_income }} * (log income - 10.70)/0.45 + {{ truth.coefficients.debt_ratio }} * debt_ratio + {{ truth.coefficients.z_credit_history }} * (credit_history_years - 8)/5 + {{ truth.coefficients.prior_delinquencies }} * prior_delinquencies + {{ truth.coefficients.loan_to_income }} * loan_to_income + {{ truth.coefficients.z_term }} * (term_months - 36)/16 + {{ truth.coefficients.z_tenure }} * (employment_tenure - 6)/5 + employment_effect + region_effect + channel_effect(month) + {{ truth.coefficients.missing_income }} * 1[income missing] + {{ truth.coefficients.missing_credit_history }} * 1[credit history missing] b0 = {{ truth.coefficients.intercept }} default ~ Bernoulli(sigmoid(logit))

Numeric features enter as z-scores against fixed constants rather than sample statistics, which is what makes the estimated-versus-true coefficient comparison below meaningful. Note the last two terms: missingness itself carries risk, so an applicant with no usable income figure is genuinely more likely to default, independently of what that income would have been.
