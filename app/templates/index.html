Control centre

One question, asked honestly: will this credit model still be accurate, calibrated and profitable six months after it goes live? Everything below is computed at seed time from a synthetic population with drift deliberately built into it.

Synthetic data. All {{ meta.rows | fnum(0) }} applicants are generated by app/generate.py from a documented data-generating process. Nothing here is real lending data and no number should be read as a market benchmark. The point of using a known DGP is that the drift is planted, so the detectors below can be scored rather than trusted. See Data for the full generation methodology.
